# JavaScript Project — Minimal Setup

This workspace contains a minimal Node.js scaffold.

Quick start (Windows):

Install dependencies:

```bash
npm install
```

Run the app:

```bash
npm run start
```

Run tests:

```bash
npm test
```

Add ESLint + Prettier (optional):

```bash
npm install -D eslint prettier eslint-config-prettier eslint-plugin-prettier
npx eslint --init
```
